# ON7 // NetHunter Field Manual

Experiencia web interactiva en español sobre un Samsung Galaxy On7 modificado como plataforma portátil de investigación con Kali NetHunter.

Incluye visualizaciones animadas de:

- cartografía RF durante recorridos a pie;
- evaluación de seguridad automotriz en laboratorio;
- flujo de pentesting autorizado;
- análisis de perfiles Bluetooth.

El contenido es educativo y conceptual. No incluye procedimientos ofensivos operativos.

## Sitio

[Abrir la publicación en GitHub Pages](https://ggonzalospineli-ops.github.io/on7-nethunter-field-manual/)

## Desarrollo local

El sitio es HTML/CSS estático y se publica desde `dist/`.

```powershell
cd dist
python -m http.server 8787
```
